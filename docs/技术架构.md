# AxMusic 技术架构

## 1. 技术栈

| 层 | 选型 | 说明 |
|----|------|------|
| 壳 | **Tauri 2**（Rust） | 交付绿色版 exe |
| UI | React + TypeScript + Vite | 见《界面设计》 |
| 工作库 | SQLite | 仅「管理」工作区；播放可不依赖 |
| 标签 | **lofty**（+ TagLib 备用） | FLAC/MP3/M4A/Opus |
| 声纹 | Chromaprint / AcoustID | 可选 |
| HTTP | reqwest | 刮削 API |
| 播放 | **Symphonia + cpal**（MVP 可 rodio） | 见下节 |

## 2. 播放引擎

**主路径：Symphonia 解码 + cpal/WASAPI 输出**；接口 `PlayerEngine` 便于换后端。

| 方案 | 绿色单文件 | 评价 |
|------|------------|------|
| **A. Symphonia + cpal** | 易 | **推荐**：许可干净、可控 |
| B. rodio | 易 | MVP 先跑通 |
| C. libmpv | 难（dll） | 质量天花板，必要时再换 |
| D. BASS | 易 | 商业授权受限 |

**自研能力优先级**：P0 播放/seek/队列；P1 gapless、ReplayGain、媒体键（**souvlaki**）、设备切换；P2 WASAPI 独占 bit-perfect、交叉淡化。

```rust
trait PlayerEngine {
    fn open(&mut self, path: &Path) -> Result<TrackInfo>;
    fn play(&mut self);
    fn pause(&mut self);
    fn seek(&mut self, ms: u64) -> Result<()>;
    fn set_queue(&mut self, items: Vec<QueueItem>);
    fn set_output_device(&mut self, id: &str) -> Result<()>;
    fn position(&self) -> u64;
    fn volume(&self) -> f32;
}
```

## 3. 模块

```text
UI: 播放浏览 + 侧栏「管理」+ 全局迷你播放条
        │ IPC
Core: scanner · tagger · scraper · lyrics · organizer · library · media_browse · player
        │ HTTPS
外部: MusicBrainz · Cover Art Archive · AcoustID · LRCLIB ·（可选）Discogs / 中文歌词源
```

| 模块 | 职责 |
|------|------|
| scanner | 遍历库目录、读标签、增量扫描、写档案 |
| scraper | 在线候选 → **只写入本地 catalog**，不写音频 |
| tagger | catalog → 文件 tags/封面 原子写 |
| catalog | 在线元数据本地子集 + `covers/` 引用 + tracks 关联 |
| catalog | 在线元数据本地子集 + `covers/` 封面引用 + 与 tracks 关联 |
| lyrics | LRCLIB 等；LRC；内嵌/外挂 |
| organizer | 模板路径、清洗、预览、移动 |
| library | SQLite 工作库 + FTS；库根配置 |
| playlists | m3u8 歌单读写（`<库>/playlists/`，相对路径，播放不依赖 DB） |
| media_browse | 目录+标签直读；轻缓存可选 |
| player | `PlayerEngine` + 队列 |

**数据流**：刮削（MB 候选→catalog+covers/）→ 匹配（tracks↔catalog）→ 管理表 diff → 写回文件。刮削**不**改写音频。

**并发**：扫描/写盘/网络在 Rust 侧；写文件单队列；MB 限速约 1 req/s。

## 4. 在线数据源

| 用途 | 首选 | 说明 |
|------|------|------|
| 曲目/专辑 | **MusicBrainz + iTunes + 网易云 + QQ音乐** 四源聚合 | 候选带来源徽标；MBID 匹配仅认 MB 源；各源 id 写入 catalog.source 隔离 |
| 声纹 | AcoustID | API key |
| 封面 | **多源**：Cover Art Archive / iTunes / 网易云 / QQ音乐 | 候选挑选；CAA 按 MBID 最精确但托管 archive.org（国内可能需代理），iTunes/网易/QQ 国内直连 |
| 歌词 | **LRCLIB** | 无需 key；中文源可选默认关 |

匹配顺序：已有 MBID → 声纹 → 专辑搜索 → 单曲搜索。  
歌词默认：**LRC 文本 + 外挂 .lrc**（比 SYLT 兼容好）。  
缓存于 `data/cache/`；合规：署名、限速、不镜像库。

## 5. 数据模型（管理工作库 `axmusic.db`）

> 播放**不强制**依赖本库。歌单是磁盘 m3u8。

**主要表**：`catalog`（在线元数据子集）、`tracks`（文件当前 tag + catalog_id）、`path_map`（整理映射预留）、`library_roots`、`file_operations`。

**存放位置**：工作库 `axmusic.db` 在**库目录**内。软件设置 JSON：`data_root/settings.json`。封面（含缩略图缓存）都在库目录：刮削封面 `<library_root>/covers/<mbid>.jpg`、管理表缩略图 `<library_root>/covers/.thumbs/`（**不**存进 SQLite；写回时嵌入 tag）。

**tag_status**：`unmatched` / `partial` / `complete`（供管理表筛选）。

**标签映射（摘要）**

| 逻辑 | FLAC | MP3 | M4A |
|------|------|-----|-----|
| title | TITLE | TIT2 | ©nam |
| artist | ARTIST | TPE1 | ©ART |
| albumartist | ALBUMARTIST | TPE2 | aART |
| album | ALBUM | TALB | ©alb |
| date | DATE | TDRC | ©day |
| track | TRACKNUMBER | TRCK | trkn |
| lyrics 纯文本 | LYRICS | USLT | ©lyr |
| lyrics 同步 | LYRICS(LRC)/旁路 | USLT(LRC) | ©lyr |
| cover | METADATA_BLOCK_PICTURE | APIC | covr |

内部统一 `TrackMeta`（title, artists[], album, …, lyrics, cover, mbid…）。

## 7. 绿色版打包

| 要求 | 做法 |
|------|------|
| 免安装、可挪窝 | zip 解压即用 |
| 入口 | `AxMusic.exe`；**优先单文件**，兜底文件夹 |
| 数据 | `exe_dir/data/`（便携）；`AxMusic-portable.ini` 可强制便携 |
| 库目录 | 用户音频，在库根，**不**打进发行包 |
| 产物 | `AxMusic-x.y.z-win64-portable.zip` |

数据根解析：有 `data/` 或 portable.ini → `exe_dir/data`，否则 `%APPDATA%/AxMusic`。  
代码统一 `paths::data_root()`，禁止写死路径。

构建：`npm run build` → `cargo tauri build` → `package-portable.ps1`。  
验收：中文+空格路径可跑、便携不写 APPDATA、删文件夹即卸载。

## 8. 风险

| 风险 | 对策 |
|------|------|
| 中文/冷门专辑匹配差 | 声纹+手动搜索 |
| 写标签损坏文件 | 原子写（临时文件+rename） |
| API 限速 | 限速器+缓存 |
| 单文件杀软误报 | 签名/说明；兜底文件夹版 |
