# AxMusic 产品需求

## 1. 定位

**具备管理功能的音乐播放器**（Windows）：默认听歌；侧栏「管理」做批量洗库（标签/封面/歌词/刮削/整理）。

格式以 **FLAC** 为主，兼顾 MP3 / M4A / Opus。

**产品模型**

1. 默认是播放器，管理是内嵌工作区，不是另一套软件
2. 扫描结果是初步档案（可缺可错），先入库再完善
3. 标签不全也能搜、能播；整理/刮削可选
4. 界面见《界面设计》；技术见《技术架构》

### 1.1 库目录（管理前提）

播放可开**任意路径**；管理只面向**库目录**。

```text
【播放】任意文件 ──「纳入库管理」──► 复制进库 / 登记路径
【管理】新建或选择已有目录 → 初始化 → 手动放入音频 → 刷新扫描 → 洗库
```

| 编号 | 需求 |
|------|------|
| FR-LIB-01 | 进「管理」若无库根：向导 **新建目录** 或 **选择已有目录** |
| FR-LIB-02 | 新建：指定父路径+文件夹名，创建并**初始化** |
| FR-LIB-03 | 选择已有：指定现有文件夹为库根并**初始化**（不强制搬迁） |
| FR-LIB-04 | 初始化后可扫描；也可先手动放入音频再 **刷新** |
| FR-LIB-05 | 刷新 = 增量扫描（新建档、删除标记、变更更新） |
| FR-LIB-06 | 可更换库根；MVP 单库根 |
| FR-LIB-07 | **纳入库管理**：仅**库外**曲目 → 复制进库 |
| FR-LIB-08 | 播放不要求在库内；应用数据在 `exe_dir/data`（与库目录分离） |

### 1.2 界面结构

单壳播放器 + 侧栏「管理」工作区（详细见《界面设计》）：

- 启动默认播放浏览；侧栏含「管理」；**迷你播放条全局常驻**
- 管理页：文件表 / 刮削 / 整理；播放浏览只读，可右键进管理

## 2. 范围

**格式**：P0 FLAC、MP3；P1 M4A/ALAC、Opus/Ogg；P2 WAV/AIFF、DSF 等。

**非目标（首版）**：流媒体账号同步、多用户/远程库、手机端、格式转换/DSP、DRM。

## 3. 功能需求

### 3.1 扫描与初步档案

- 扫描库目录（含子目录）；解析时长/比特率/采样率/封面/标签
- 建立初步档案 + **字段完整度**；增量扫描；可选声纹
- 后台扫描可播放；读失败进「问题」列表

### 3.2 档案维护（文件 ↔ catalog）

- 管理表展示**文件当前**字段；选中 → 与 **catalog** 对比
- 用户决定是否把 catalog **写入文件**（标签/封面）
- 原子写回

### 3.3 刮削（云端 → 本地 catalog）

- 候选确认后**只写入 catalog** + 封面到 `<库>/covers/`
- **不**改写音频文件；写回见 3.2

### 3.4 歌词

- 在线搜索；纯文本 + LRC 时间戳；内嵌 / 外挂 `.lrc` / 两者
- 编辑器；多候选排序；支持粘贴

### 3.5 文件整理

- 模板重命名/移动（见下）；预览 + 冲突检测；未匹配不强制整理
- 多套整理方案

### 3.6 浏览与管理表

- 播放：歌曲 / 专辑墙 / 歌手 / 文件夹 / 流派 / 正在播放
- 管理表：字段状态列（封/词/年/型/MB）、缺失筛选、多选补封面/歌词/刮削

### 3.7 播放列表

- 磁盘 `.m3u8/.m3u`；新建/排序/导入；队列可另存

### 3.8 播放

- 播放/暂停/切歌/进度/音量/顺序·随机·单曲；全局迷你条 + 播放页
- LRC 滚动；输出设备；快捷键；未完善标签也能播

### 3.9 界面

美观现代化，见《界面设计》（禁止 Win32 灰面板拼贴风）。

## 4. 非功能

| 项 | 要求 |
|----|------|
| 平台 | Windows 10/11 x64 |
| 性能 | 万级文件后台扫描不卡 UI |
| 安全 | 写标签原子写回；改名可备份；不上传音频文件 |
| 合规 | MusicBrainz 等限速、UA、署名 |
| 离线 | 已有文件可离线浏览播放 |
| **分发** | **绿色版 exe**（见《技术架构》打包节） |

## 5. 主路径

```text
启动 → 听歌（任意路径）
  → 侧栏「管理」→ 库目录向导 → 初始化
  → 手动放入 → 刷新扫描 → 补字段/刮削/整理
  → 回去听歌；库外好歌「纳入库管理」
```

## 6. 文件整理规则（摘要）

目标结构示例：`库根\{albumartist}\{year} - {album}\{track} - {title}.flac`

**模板变量**：`{title}` `{artist}` `{albumartist}` `{album}` `{year}` `{date}` `{track}`（两位补零）`{disc}` `{genre}` `{format}` `{composer}` `{custom:xxx}` 等。

**内置方案**：

| 名 | 路径模板 | 文件模板 |
|----|----------|----------|
| lossless-archive（默认） | `{albumartist}\{year} - {album}\` | `{track} - {title}` |
| flat-by-album | `{albumartist} - {album} ({year})\` | `{track} - {title}` |
| classical | `{composer}\{album} ({year})\` | `{disc}-{track} - {artist} - {title}` |

**清洗**：替换 `<>:"/\|?*`；去首尾空白/点；保留名加 `_`；空字段回退 Unknown*；路径过长警告。

**预览状态**：OK / SAME / RENAME_ONLY / MOVE / COLLISION / INVALID_TAG / PATH_TOO_LONG。  
**执行**：同盘 rename；跨盘 copy+校验+删源；记 `file_operations`。  
**顺序**：标签 → 封面/歌词 → 整理。

## 7. MVP 验收

1. 设置库目录（新建/已有）→ 初始化 → 手动放入后刷新扫描 500+ FLAC  
2. 管理表能按缺字段筛选并批量刮削（候选含正确项）  
3. 歌词写入后 foobar2000 等可读出  
4. 整理预览零破坏，执行后符合模板  
5. 歌单 + 完整听完一张专辑  
6. 库外曲目「纳入库管理」  
7. 除刮削 API 外无文件内容外传；绿色版可跑
