## 已定决策（勿擅自推翻）

- **定位**：带管理功能的播放器；默认播放；侧栏「管理」洗库  
- **库目录**：管理页向导（新建/已有→初始化）→ 手动放入 → 刷新扫描；播放任意路径 +「纳入库管理」  
- **格式**：FLAC 优先，MP3 次之  
- **刮削**：MusicBrainz + Cover Art Archive；歌词 LRCLIB（中文源默认关）  
- **数据**：管理工作库 SQLite；播放直读文件；歌单 m3u8  
- **播放引擎**：Symphonia + cpal（MVP 可 rodio），接口 `PlayerEngine`  
- **UI**：Gallery-First Dark Studio，现代化，见《界面设计》  
- **分发**：绿色版 exe（优先单文件），数据 `exe_dir/data`  
- **MVP**：既能听也能洗库
