# AxMusic 界面设计

**一句话**：*Gallery-First Dark Studio* — 封面是主角，工具不抢戏。对标 Apple Music 专辑墙 + Linear 控件克制；禁止 Win32 灰面板拼贴。

## 1. 布局（单壳 + 侧栏「管理」）

```text
┌───────────────────────────────────────────┐
│ 品牌区（可拖拽）│ 顶栏：标题·搜索·操作 · ─ □ × │ ← 无系统栏；窗口按钮在顶栏右缘
├────┬──────────────────────────────────────┤
│ 侧 │  主区：歌曲/专辑/歌手/歌单            │
│ 栏 │       或 管理：文件表·刮削·整理       │
│    ├──────────────────────────────────────┤
│    │  迷你播放条（全局常驻）               │
└────┴──────────────────────────────────────┘
```

默认窗口 1440×900（最小 1200×700），为管理表 + 常驻右栏留空间。拖拽/双击最大化：侧栏品牌区 + 顶栏空白（`data-tauri-drag-region`）。

**侧栏**

```text
AxMusic vX.Y.Z
歌曲 · 专辑 · 歌手 · 目录 · 歌单
────────
管理          ← 洗库工作区
设置
────────
（预留：主页歌词显示）
```

满窗播放不进侧栏：迷你条左下封面小图点击打开；满窗右上「缩回」回主界面。

**管理首进（无库根）向导**：新建目录 ｜ 选择已有目录 → 初始化 → 手动放入 → 刷新扫描。

曲目菜单「纳入库管理」仅库外文件。无双模式顶栏开关。

## 2. 色彩 Token（暗色）

| Token | Hex | 用途 |
|-------|-----|------|
| bg | `#0B0C0F` | 窗口底 |
| bg-elevated | `#12141A` | 侧栏/面板 |
| bg-card | `#181B23` | 卡片 |
| bg-hover | `#222632` | 悬停 |
| border | `#2A2F3A` | 描边 |
| text / secondary / tertiary | `#F2F4F8` / `#A8B0BE` / `#6B7385` | 文字 |
| accent | `#7C6AF2` | 主按钮/选中/进度 |
| success / warning / danger | `#3DDC97` / `#F5C542` / `#FF6B7A` | 完整 / 缺字段 / 失败 |

浅色：`#F7F8FA` 底。封面取色仅作氛围渐晕（≤35% 透明度）。

**外观 × 皮肤（设置页「外观 / 皮肤」）**
- 外观：暗色 / 浅色（`html[data-theme]`）；顶栏右侧（窗口按钮前）有太阳/月亮快捷切换，与设置共用 `theme_mode`
- 皮肤：星云紫（默认）/ 天空蓝 / 翡翠绿 / 玫瑰粉 / 琥珀金 / 珊瑚橙 / 石墨灰（`html[data-color-scheme]`）
- **表面中性灰/浅灰，不随皮肤偏色**；皮肤只换 accent 家族（`--accent` 文字用加深/浅色实心 `--accent-solid`）+ `--on-accent`
- 状态色与几何/字体共用
- **满窗播放不跟主题**：背景为封面氛围层，固定深色 + 白字（见 NowPlayingPage.css）

## 3. 字体

Segoe UI Variable（中文回退雅黑）：正文 13px；Display 28–32/600；路径等宽 Cascadia 12px；歌词 15–16px。

## 4. 间距与控件

- 间距 4/8/12/16/24/32；圆角：控件 8、卡片 12、封面 8–10  
- 顶栏 52px（窗口按钮 46px 紧贴右缘）；侧栏 220px（可收 56px）；表行高 40  
- 主按钮：高 32、accent 底；输入 focus `accent-soft` 环  
- 卡片少阴影、靠边框分层；图标统一 Lucide/Phosphor  

## 5. 关键界面

### 专辑
封面 1:1 卡片；悬停浮起+播放钮；缺封面灰阶+首字母。点卡片进**专辑详情**（大封面 + 曲目表 + 播放全部/加入歌单/返回）；封面按样例曲目懒加载。

### 歌曲
全库曲目列表；**列表 / 卡片网格**双视图（顶栏切换，记忆偏好）；搜索过滤；点行/点卡播放；可全部或单曲加入歌单。列表含**喜爱**心形列（空心未爱 / 实心 danger 色已爱），歌曲名旁同样可点切换。

### 目录
左树右表：左栏完整目录树（懒加载展开，根=用户所选任意路径，默认库根/上次根）；右侧当前目录音频（曲名·歌手·文件名·时长）。顶栏「含子文件夹」递归列出（带上限）、「选择目录」、「播放全部/选中」、「加入歌单」。文件行勾选多选（Shift 连选），点曲名播放；有选中时操作只作用于选中。

列表**先出文件名**（不阻塞读标签）；标签走 `data_root/cache/folder_tags.db`（path+mtime+size），命中即填，未命中后台分批补并写缓存。不依赖库。

### 文件管理表（洗库）
- 列：✓ ｜ 封面 ｜ 曲名 ｜ 歌手 ｜ 专辑 ｜ 年份 ｜ 轨号 ｜ 内嵌歌词 ｜ 外挂歌词（如实展示文件当前标签值，不再用勾/缺符号；歌词两列布尔展示，有 → 绿 ✓）；表头不缩写
- 封面列：文件内嵌封面缩略图（32px，懒加载 + 磁盘缓存）；无封面占位图标
- **绿字规则**：字段值与关联 catalog 一致（trim + 忽略大小写；年取前 4 位；轨号按数值）→ success 绿，否则白色；空值显示弱化「—」。绿字本身即关联指示，不再单设「联」列
- 顶栏：库根路径 +「更换库根」「刷新扫描」；工具行左起搜索框，再过滤芯片 + 共 X 首（无「自动关联」）
- **右栏常驻 380px，与工具行同高上顶**：底部固定「播放 / 歌单」一排（作用于多选或当前激活行）；未选中行 → 库统计；选中行 → 标题「刮削 / 🔍歌词」一排 + catalog 字段列表（值居中，逐字段写入文件）；未关联 catalog → 可编辑文件字段 +「写入文件」（写后自动尝试关联）；封面区单张展示（优先 catalog，退回文件），下一行「刮取/重新刮取封面」「写入封面」（无关闭按钮，再点一次选中行或点空白回到统计）

### 搜索歌词（弹层）
右栏对比面板「搜索歌词」打开，单首曲目。**打开不自动搜索**：歌手/歌名输入框（预填文件标签，可改），点「搜索」或回车手动触发；LRCLIB/网易云/QQ音乐 并发流式返回。候选 → 预览 → 保存为外挂 .lrc（默认）/ 内嵌；支持嵌↔挂互转。
- 本地可参考 `ui-wireframe-table.svg`（已 gitignore，不入库）

### 刮削向导
**单曲**两栏：云端候选 | 写入 **catalog** 的字段 diff；「存入本地 catalog」（不写音频）。封面→边栏单独刮取到 `<库>/covers/`。

### 整理预览
旧路径→新路径对照；冲突未解决不能执行。

### 播放
迷你条常驻（封面小图可点开满窗）；满窗：全幅封面模糊底 + 大封面光晕，右侧 LRC 居中滚动（当前行放大发光，点歌词跳转）；底部渐变进度条 + 大圆播放键；右上「缩回」。无歌词/纯文本也能优雅展示。

**播放列表记忆**：队列/当前曲写入 `data_root/play_session.json`（播放变更、退出时落盘；进度不记）；下次启动恢复为**暂停**在曲目开头，点播放继续，不自动播。

## 6. 动效与文案

切换 120–180ms ease-out；stagger ≤300ms；尊重减少动效。  
文案短、动词开头；错误写清怎么办。

## 7. 实现约束

- Token 进 CSS variables，禁止散落写死颜色  
- 大列表虚拟化；封面防 CLS  
- 界面验收：键盘可完成主路径；对比度达标；截图应像现代暗色音乐产品  
- 全局屏蔽原生右键菜单；定制菜单区域标 `data-context-menu` 并自行 `onContextMenu`（如满窗播放）  
- 系统托盘常驻：左键/双击显示主界面，右键「显示 / 退出」；关闭主窗口按设置「询问 / 缩到托盘 / 退出」，询问弹窗可勾选「下次不再询问」
