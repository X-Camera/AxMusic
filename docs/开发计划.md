# AxMusic 开发计划

阅读顺序：`README.md` → `docs/产品需求.md` → `docs/技术架构.md` → `docs/界面设计.md` → `docs/歌曲归档.md`（归档规范）。线框 SVG 仅本地参考，已 gitignore。

## 已定决策（勿擅自推翻）

- **定位**：带管理功能的播放器；默认播放；侧栏「管理」洗库  
- **库目录**：管理页向导（新建/已有→初始化）→ 手动放入 → 刷新扫描；播放任意路径 +「纳入库管理」  
- **格式**：FLAC 优先，MP3 次之（实际已覆盖 FLAC/MP3/M4A/Opus）  
- **刮削**：MusicBrainz（文字）+ 封面多源（CAA/iTunes/网易云/QQ音乐，候选挑选）；歌词 LRCLIB + 网易云 + QQ音乐 多源聚合  
- **数据**：管理工作库 SQLite（tracks/catalog 两世界）；播放直读文件；歌单 m3u8（`<库>/playlists/`，相对路径）  
- **刮削不改文件**：采纳只写 catalog + `covers/`；写文件走对比面板勾选（空值永不覆盖）  
- **歌词默认外挂 `.lrc`**；保存可选内嵌；满窗/子窗口均可搜、可替换；库外文件按 path 搜存  
- **歌曲归档**：`archived/{歌手}/歌手 - 歌名.ext`（版本括号保留原名）；库根杂项进 `Unarchived/`；见《歌曲归档》。§6 模板整理降级为后续高级整理  
- **搜索歌词 = 独立 Tauri 子窗口**（无系统标题栏，可拖出主窗）  
- **设置页**：左设置分组 + 右软件介绍定栏；播放模式（顺序/随机/单曲）已接引擎  
- **播放引擎**：Symphonia + cpal，接口 `PlayerEngine`  
- **UI**：Gallery-First Dark Studio，自绘标题栏，颜色/间距走 `tokens.css`  
- **分发**：绿色版 exe，数据 `exe_dir/data`（`paths::data_root()`）  
- **MVP**：既能听也能洗库  
- ~~写标签前备份~~ 已移除（用户决策）  
- ~~刮削采纳时写封面（scrape_write_cover）~~ 设计已废弃，设置项已删
